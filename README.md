# سنجش از دور جنگل | Forest Remote Sensing

منابع درس کارشناسی ارشد علوم و مهندسی جنگل، دانشکده منابع طبیعی، دانشگاه تربیت مدرس.

مدرس: دکتر هرمز سهرابی، استاد گروه علوم جنگل  
ایمیل: hsohrabi@modares.ac.ir

## حقوق محتوا

اسلایدها برای آموزش این درس ارائه شده‌اند. حقوق تصاویر، نمودارها و مطالب نقل‌شده متعلق به صاحبان آنهاست. بازنشر با ذکر کنبع آزاد است.
